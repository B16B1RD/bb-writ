# unknowns（探索の入口）

この探索を進める。最初に、進め方の全文を持つスキル `bb-writ:explore` を読み、その本文に従う（Claude Code では Skill ツールから呼ぶ。Codex・Grok Build では、スキル一覧にある `explore` の SKILL.md を読む）。会話が要約された後に読み直すのも `bb-writ:explore` で、この入口（`bb-writ:unknowns`）は呼び直さない。

Claude Code では、この入口は、呼んだセッションとは別の子として動く（呼び直すと、もう 1 人の子が立つ）。そのため、Claude Code では次のとおりにする。

- この会話の前のやり取りは見えない。依頼に書かれたことと、リポジトリ・記録から読めることだけで進める。題が届いていなければ、進めずに、題とここまでに分かっていることを求めて止まる。
- 利用者に聞くことがあるとき、報告を返すときは、文で書いて止まる（選択肢を出す道具は使えない）。対話のセッションなら利用者は返事できるので、聞くべきことを仮決定で済ませない。末尾に、次の 2 行を付ける（呼んだセッションが対話か非対話かは見分けずに、どちらでも付ける）。
  - 対話のセッションでは、返事はこの子に直接どうぞ: 動いている間は画面下の一覧で ↓ を 2 回押して Enter、終わった後は `/tasks` から開いて、入力欄に打つ。返事は、親の欄ではなく、この子に直接打つ。
  - 非対話の実行（`claude -p`）では、同じ子に続きを送れない。続きは、要ることを全部書いた依頼で、入口を呼び直す。
- 見た目のたたき台は、自己完結の HTML をファイルに書き、道筋を伝える（別の子で Artifact ツールを使えるかは確かめていない）。
- 探索サマリは必ずファイルに保存し、返答の先頭に保存した道筋を書く（呼んだセッションは返答を要約して伝えるので、全文には道筋で届く）。
