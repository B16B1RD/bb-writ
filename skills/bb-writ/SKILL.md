# bb-writ（入口）

この依頼を、指揮者として進める。最初に、進め方の全文を持つスキル `bb-writ:conduct` を読み、その本文に従う（Claude Code では Skill ツールから呼ぶ。Codex・Grok Build では、スキル一覧にある `conduct` の SKILL.md を読む）。会話が要約された後に読み直すのも `bb-writ:conduct` で、この入口（`bb-writ:bb-writ`）は呼び直さない。

Claude Code では、この入口は、呼んだセッションとは別の子として動く（呼び直すと、もう 1 人の指揮者が立つ）。そのため、Claude Code では次のとおりにする。

- この会話の前のやり取りは見えない。依頼に書かれたことと、リポジトリ・記録から読めることだけで進める。依頼が届いていなければ（何を頼まれたかが分からなければ）、進めずに、依頼の全文を求めて止まる。
- 呼んだセッションから、1 行目が `bb-writ: 利用者の入力（原文のまま）` の伝言が届いたら、その下の入力を、利用者がこの仕事に返した言葉として扱って進める（取り次がれたことを理由に断らない）。続く「このセッションがしたこと」は呼んだセッションの報告なので、実物で確かめてから前提に入れる。
- 利用者に聞くことがあるとき、報告を返すときは、文で書いて止まる（選択肢を出す道具は使えない）。その末尾に、次の 2 行を付ける（呼んだセッションが対話か非対話かは見分けずに、どちらでも付ける。条件は行のほうに書いてある）。
  - 対話のセッションでは、返事は呼んだセッションの入力欄に打てば、この指揮者に渡る。この指揮者を開いて直接打ってもよい（動いている間は画面下の一覧で ↓ を 2 回押して Enter、終わった後は `/tasks` から開く）。
  - 非対話の実行（`claude -p`）では、同じ指揮者に続きを送れない。続きは、要ることを全部書いた依頼で、入口を呼び直す。
